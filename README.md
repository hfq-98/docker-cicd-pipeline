Automated Web Deployment Pipeline (CI/CD)
A proof-of-concept Continuous Integration and Continuous Deployment (CI/CD) pipeline demonstrating automated testing and containerization.

Project Overview
This repository contains the infrastructure-as-code and configuration files required to automatically build and deploy a Node.js web application. It was designed to explore modern DevOps practices and streamline the deployment lifecycle.

Technologies Used
Containerization: Docker

CI/CD Automation: GitHub Actions

Application Environment: Node.js
